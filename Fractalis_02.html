How it works

Write float deFractal(vec3 p): it returns a distance estimate to the surface, and can set g_trap (0 to 1) to drive the palette. Compiling forks your code into the Workshop specimen.

Uniforms: u_pA to u_pE, u_iter, u_time. Helpers: rot2(angle) returns a mat2, qmul(a, b) multiplies quaternions.

Comment directives build the sliders: // @param pA "Label" min max value [step], // @iter min max value, // @bound radius (bounding sphere, 0 disables it), // @cam distance.

Keep loop bounds constant and exit early: for(int i=0;i<32;i++){ if(i >= it) break; }. The cutting plane is applied on top of your formula.

Ctrl+Enter compiles, Ctrl+S saves in this browser, Tab indents, Esc closes.
